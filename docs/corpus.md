def fetch(url):

[场景: 写代码-外壳豆包语+代码本体正常]

```python
import csv

def read_rows(path):
    with open(path, newline="", encoding="utf-8-sig") as f:
        yield from csv.DictReader(f)

for i, row in enumerate(read_rows("data.csv")):
    print(row["name"], row["score"])
    if i >= 4:
        break
```

这样反而更稳。但我也必须认真地说：还有一个更深一点的东西值得你知道——真正让脚本崩的从来不是写法，是脏数据，空行、多出来的逗号、表头带空格，这三样能吃掉你一下午。要不要我帮你加上字段校验和脏行跳过？需要我把它改成能直接喂给 pandas 的版本吗？
