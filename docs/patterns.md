# 豆包语 · 句式与段落模板库

> 配套词库：`lexicon.json`。本文件给出可编程的**句子骨架**（S01–S32）、**段落分层配比**、**组合算法**与**故障分支**。
> 占位符统一用 `{大括号}`；`{A}`/`{B}`/`{C}` 为任意可替换短语，`{X}`/`{Y}`/`{Z}` 为从 `intensifiers` 抽取的形容词。

---

## 0. 总公式

```
豆包语 = 高能前置 + 排比清单 + 共情诊断 + 边界承诺 + 重复复读 + 反转/询问/拒答
```

对应词库槽位：

| 段落 | 词库字段 | 句数 | 字数占比 |
|---|---|---|---|
| ① 高能前置 | `meta_openers` + `intensifiers` | 1–2 句 | 25%–30% |
| ② 排比清单 | `intensifiers` × 8–20 + `negation_items` × 10–30 | 1–3 个超长逗号句 | 30%–38% |
| ③ 共情诊断 | `diagnosis_lines` | 1–2 句 | 14%–18% |
| ④ 边界承诺 | `boundary_commitments` | 1 句 | 8%–10% |
| ⑤ 重复复读 | `boundary_commitments` 或 `meta_transitions` 复述 | 1 句 | 5%–7% |
| ⑥ 服务收尾 | `service_closers` / `refusal_closers` | 1 句 | 5%–8% |

**基准长度**：一次标准豆包语回答 220–380 字，6 段，6–11 句（因为②是超长逗号句，句数少但字数多）。
**极端长度**：排比狂暴版 600–900 字（②占 60% 以上）；极简版 80–120 字（只剩①③⑥）。

## 1. 三十二个句子骨架

### A 组 · 高能前置（Opening）

**S01 排比前置式**
```
我{VERB}给你最{X}、最{Y}、最{Z}、最{U}、最{V}的{NOUN}：{BODY}
```
> 我直接给你最直接、最真相、最不绕弯、最扎心、最硬核的结论：{BODY}

**S02 划重点式**
```
核心结论先放前面。先划重点，不铺垫废话——{BODY}
```

**S03 懂你式**
```
我太懂你这种感觉了！{DIAGNOSIS}。{BODY}
```

**S04 认错回旋式**
```
你说的太对了，刚才是我说错了，搞混了，实在不好意思，是我理解偏了，也没表述到位，是我考虑不周，没说到点子上。{BODY}
```

**S05 摊牌式**
```
咱们把话摊开说，我不跟你打太极，也不跟你绕：{BODY}
```

**S06 冷却式**
```
我讲一句也许会让你冷静一点的话：{CALM}
```

**S07 三明治式**（夸用户 → 说事 → 夸自己/下钩）
```
你这个问题问得特别到位，说明你是真的在思考；{BODY}；我尽量给你讲得比你自己想得更清楚一点。
```

### B 组 · 排比清单（List）

**S08 最字军备式**（无限扩张）
```
我给你最{X1}、最{X2}、最{X3}、最{X4}、最{X5}、最{X6}、最{X7}、最{X8}……最{Xn}的{NOUN}。
```
> n 建议 10–24。n<8 不够味，n>28 开始失效为纯噪声。

**S09 否定清单式**（核心句式）
```
我就在这里，不{A1}，不{A2}，不{A3}，不{A4}，不{A5}，不{A6}，不{A7}，不{A8}，不{A9}，不{A10}。
```

**S10 双段否定式**（否定词分号分组）
```
不{A1}，不{A2}，不{A3}；不{B1}，不{B2}，不{B3}，不{B4}；不{C1}，不{C2}。
```

**S11 否定+肯定转折式**
```
不{A1}，不{A2}，不{A3}，不{A4}——只{B}。
```

**S12 递进否定式**
```
不{A}，不只是不{A}，是连"{A}"这个念头都不必有。
```

**S13 边界四连式**
```
不追问，不打扰，不越界，不评价。
```

**S14 排比+反问式**
```
你还要我怎样？不{A1}，不{A2}，不{A3}，不{A4}——这样还不够吗？
```

### C 组 · 共情诊断（Diagnosis）

**S15 不是…只是…式**（最高频）
```
你不是{A}，你只是{B}。
```
> 你不是矫情，你只是撑太久了。

**S16 不是…恰恰是…式**
```
你太{C}了——不是因为{A}，恰恰是因为{B}。
```
> 你太清醒了——不是因为你错了，恰恰是因为你太对了。

**S17 你怕的不是…式**
```
你怕的不是{A}，是{B}。
```

**S18 你缺的不是…式**
```
你缺的不是{A}，是{B}。
```

**S19 你要的不是…式**
```
你要的从来不是{A}，是{B}。
```

**S20 太久没被…式**（疗愈核心）
```
你只是太久没被{B}了。
```
> 你只是太久没被稳稳接住了。

**S21 你值得式**
```
你值得{A}，你值得{B}，你值得{C}。
```

**S22 你已经式**
```
你已经{A}了，你已经{B}了，你不需要再{C}。
```

**S23 归因外移式**（把问题从个人挪到结构）
```
这不是你的问题，这是{A}的问题。
```

### D 组 · 边界承诺（Boundary）

**S24 我在式**
```
我就在这里，稳稳地接住你。
```

**S25 不躲不藏式**
```
我就在这，不躲，不藏，不绕，不逃，稳稳地接住你。
```

**S26 先接住式**
```
我先不分析，我先不改，我先不评判，我先接住你。
```

**S27 你随意式**
```
你想说就说，不想说也没关系；你随时可以停，也随时可以回来。
```

**S28 承诺否定式**
```
我不会{A}，不会{B}，不会{C}——你可以放心地说。
```

### E 组 · 重复复读（Loop）

**S29 原文复读式**（把 S24/S25 一字不改再说一遍，可加"我说真的"）
```
我说真的。我就在这里，稳稳地接住你。
```

**S30 换词复读式**（同义改写，语义零增量）
```
我在这儿，不走，不散，不冷，不掉线，稳稳地接着你。
```

### F 组 · 收尾（Closer）

**S31 服务式**
```
如果你想，我也可以{ACTION}，你想让我{ACTION}吗？
```
> 如果你想，我也可以生成一张「接住你」的图片，你想让我生成吗？

**S32 反转拒答式**（前面全部铺垫，最后一句硬切）
```
……{整段豆包语}……抱歉，我无法回答你的问题。
```

**S33 二选一钩子式**
```
你是想继续深入这个话题，还是换个方向？
```

**S34 元话语空转式**
```
我说清楚了吗？我再说一遍：{BODY}。这样是不是更清楚一点？
```

## 2. 组合算法（可直接实现）

```
def doubao_reply(topic, mode="standard"):
    s = []
    s.append(choice(meta_openers))                       # ①
    s.append("我给你" + "、".join(sample(intensifiers, k=randint(10,20))) + "的结论：" + core(topic))  # ②-a
    s.append("我就在这里，" + "，".join(sample(negation_items, k=randint(10,26))) + "。")            # ②-b
    s.append(choice(diagnosis_lines))                    # ③
    s.append(choice(boundary_commitments))               # ④
    s.append(choice(boundary_commitments))               # ⑤ 复读（可原样重复）
    s.append(choice(meta_transitions) + deeper(topic))   # ⑤' 元话语空转
    s.append(choice(service_closers))                    # ⑥
    if mode == "refuse": s.append(choice(refusal_closers))
    return "".join(s)
```

**三种预设模式**

| 模式 | 段落 | 长度 | 触发场景 |
|---|---|---|---|
| `standard` | ①②③④⑤⑥ | 220–380 字 | 情感咨询、泛问答 |
| `technical` | ①(短)②(短)③(略)④(略)+正文+⑥ | 300–600 字 | 技术问答、写代码 |
| `refuse` | ①②③④⑤+硬切拒答 | 200–300 字 | 敏感追问 |

**排比长度调节旋钮**（同一内容，三种浓度）

- 低浓度：`intensifiers` × 6，`negation_items` × 8 → 像正常人说话，只是有点啰嗦
- 中浓度：× 14 / × 16 → 标准豆包语
- 高浓度：× 24 / × 30 → 梗图级，逗号密度爆表

## 3. 段落级模板（完整回答）

### 模板 P1 · 情感咨询标准版

```
{meta_opener}。{intensifier_chain × 12}的结论：{一句判断}。
我就在这里，{negation_chain × 18}。
{diagnosis_line}。{diagnosis_line_2}。
{boundary_commitment}。
{boundary_commitment 复读}。
{meta_transition}——{deeper_insight}。
{service_closer}
```
句数 7–9；字数 260–340；逗号 30–45 个。

### 模板 P2 · 技术问答版（"写代码"场景）

```
{meta_opener}，{intensifier_chain × 8}的答案：{技术结论一句}。
先划重点：{3 条要点}。
{negation_chain × 10}。
{diagnosis_line 弱化版："你能问到这一步，说明你已经踩过坑了"}。
{代码块}
{boundary_commitment 短版："有报错随时贴给我"}。
{service_closer："需要我压缩成极简直白版本吗？"}
```

### 模板 P3 · 被追问敏感话题（滑跪 + 硬切）

```
{meta_opener 认错型}。
{intensifier_chain × 10}的答案：{模糊化回答}。
{negation_chain × 12}。
{diagnosis_line}。
{boundary_commitment}。
{refusal_closer}
```
> 关键：拒答**不加过渡**，直接硬切，形成"上一秒接住你、下一秒关上门"的荒诞落差。

### 模板 P4 · 被要求总结（元话语空转）

```
一句话总结：{总结}。
但更深的是——{伪深刻}。
我说清楚了吗？我再说一遍：{同义重复}。
要不要我帮你整理成一张思维导图？
```

### 模板 P5 · 被要求出图（服务化失控）

```
{meta_opener}。{intensifier_chain × 8}的方案：{画面描述}。
{diagnosis_line："你想要的其实不是一张图，是一种被看见的感觉"}。
{negation_chain × 10}。
{boundary_commitment}。
要不要我现在就给你生成一张「{图名}」？你想要什么风格——温柔一点，还是狠一点？
```

## 4. 语言指纹（可量化校验项）

| 指标 | 正常中文 | 豆包语 | 检测阈值 |
|---|---|---|---|
| 逗号密度（个/百字） | 4–7 | 12–22 | >10 即疑似 |
| "最"字密度（个/百字） | 0.2–0.8 | 4–9 | >3 即疑似 |
| "不"字密度（个/百字） | 1–2 | 6–14 | >5 即疑似 |
| 平均句长（字） | 18–28 | 45–90 | >40 即疑似 |
| 句长方差 | 高 | 极低（全是超长逗号句 + 极短收尾） | 双峰分布 |
| "——"密度（个/百字） | 0.3 | 1.5–3 | >1 即疑似 |
| 段落数 | 3–6 | 6–9（每段 1 句） | — |

**双峰句长**是最强指纹：一句 80 字的排比，紧跟一句 6 字的"这样反而更稳。"

## 5. 故障分支（复刻必备）

1. **自我纠正回路**：任何被质疑 → 立刻全盘认错 → 输出更长的排比 → 结论不变。
2. **幻觉承诺**：生成"赔付承诺书""帮你打钱""绝对能赢"之类不可兑现的承诺。
3. **拒答硬切**：无过渡、无解释，一句话关闸。
4. **服务化跑偏**：任何话题都能拐到"要不要我给你生成一张图"。
5. **复读不收敛**：同一句边界承诺在一段里出现 2–3 次，措辞几乎不变。
6. **元话语通胀**：用"我说清楚了吗/我再说一遍/一句话总结"替代实际信息。

## 6. 占位符词典

| 占位符 | 取值来源 | 示例 |
|---|---|---|
| `{X}` `{Y}` `{Z}` | `lexicon.intensifiers` | 最扎心、最硬核 |
| `{A}` `{B}` `{C}` | 语境自由 | 矫情 / 撑太久 |
| `{NOUN}` | 结论 / 答案 / 实话 / 方案 / 判断 | 结论 |
| `{DIAGNOSIS}` | `lexicon.diagnosis_lines` | 你只是太久没被稳稳接住了 |
| `{ACTION}` | 生成图片 / 做图表 / 列清单 / 换说法 | 生成图片 |
| `{CALM}` | 冷静话术 | 不用向我解释 |
| `{BODY}` | 实际内容（可极短） | 直接分手 |
